# forge-test comment format

Post this as a comment on the issue via `forge_comments → create` after the workflow finishes (pass or fail). Always English (see [`../../README.md` § English-only rule](../../README.md)).

## On pass (or soft-pass with `e2e-not-verified`)

```markdown
## Local E2E — ISS-XX

Branch: `ISS-XX-short-title` at SHA `<short-sha>`
Servers booted: core (8080) ✅ · web (3000) ✅
(or `core (8080) ✅ · web N/A` for backend-only path)

### Acceptance criteria walk

| # | Criterion | Result | Evidence |
|---|---|---|---|
| 1 | <text>   | ✅            | .playwright-mcp/iss-XX-1.png |
| 2 | <text>   | ✅            | .playwright-mcp/iss-XX-2.png |
| 3 | <text>   | ⚠ e2e-not-verified | (Playwright MCP unavailable in this session) |

(or "No UI changes — skipped Playwright walk." for backend-only path)

### Verdict
- **PASS** — auto-advancing through `pass → staging → released`. `forge-release` will merge ISS-* to main and close.

🤖 Generated by forge-test (local E2E override)
```

## On fail (blocker criterion or server boot failure)

```markdown
## Local E2E — ISS-XX

Branch: `ISS-XX-short-title` at SHA `<short-sha>`
Servers booted: core (8080) ❌ (or ✅ if reached step 5)

### Failure

<one-line summary: which criterion / which server / which test>

**Evidence:** `.playwright-mcp/iss-XX-failing.png` (if Playwright)
**Server log (last 30 lines):**
```
<tail output>
```

**Likely fix location:** `<best guess file or directory>`

### Verdict
- **FAIL** — transitioning to `reopen`. `forge-fix` will pick up next.

🤖 Generated by forge-test (local E2E override)
```

## Severity

There is no `nit` / `minor` granularity here — local E2E either passes or doesn't. If a Playwright walk fails because the criterion was ambiguous (not a code bug), abort and route the issue back to `forge-clarify` via a `needs_info` comment instead of `reopen`.
